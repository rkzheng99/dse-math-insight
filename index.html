AI 分析

視覺模型連線

填入你自己的 OpenAI 相容視覺模型設定，即可在「試卷分析」直接把照片送進模型。金鑰只儲存在這台瀏覽器，不會傳送到其他地方。

關於瀏覽器直接呼叫

部分 API 服務不允許網頁直接連線（CORS 限制）。若出現連線錯誤，可改用「貼上分析結果」：按一下該頁的「複製專用提示詞」，把提示詞與試卷照片交給任何支援圖片的 AI 工具，再貼回 JSON 即可。

資料

備份與還原

所有資料只存放在你目前使用的瀏覽器，不會自動與其他老師或其他電腦同步。要把資料交給別人、或更換裝置，請匯出 JSON 備份再由對方「從備份還原」；建議定期備份。
